Как это работает

Это userscript — небольшой JavaScript, который браузер автоматически выполняет при открытии страниц gtifem.ru/dekanat/raspisanie/.... В правом нижнем углу появляется зелёная кнопка «📅 Моё расписание». Клик — открывается окно с поиском по преподавателям и группам, выбираете себя — попадаете в Apple/Google Calendar.

✓ Не меняет сам сайт ФЭМ. Скрипт работает локально в вашем браузере, никакие данные никуда не отправляются. На сайте появляется только кнопка.

4В правом нижнем углу — зелёная кнопка «📅 Моё расписание»

Клик → окно поиска → «Открыть» рядом с вашим именем → подписаться в Календаре.

На iPhone / iPad через Safari

На iOS используется приложение Userscripts (бесплатное от Justin Wasack).

  1. Установите Userscripts из App Store
  2. Включите расширение в Настройках iPhone → Safari → Расширения → Userscripts
  3. В Userscripts выберите папку для скриптов (любая, например iCloud Drive)
  4. Откройте на телефоне эту ссылку с .user.js
  5. Подтвердите установку
⚠ Заметка про iOS: Safari иногда требует перезагрузить страницу один раз, чтобы расширение «увидело» новый сайт. После — работает.

FAQ

Кнопка появится на ВСЕХ страницах gtifem.ru?

Нет, только на страницах расписания (/dekanat/raspisanie*).

Это безопасно?

Да. Скрипт работает только в вашем браузере, не отправляет ничего во внешние сервисы. Исходный код открыт: посмотреть на GitHub.

Где брать обновления?

Tampermonkey автоматически проверяет обновления раз в день.

Как удалить?

В Tampermonkey → Dashboard → найдите «Расписание ФЭМ» → значок корзины.
